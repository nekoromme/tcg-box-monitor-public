## 運用方針

既存監視の安定を確認 → ホビーステーション公式Yahoo!店を第一候補として検証 → 1店だけ反映 → 24〜48時間観察 → 次の候補へ。取得不能な候補に固執せず、理由と再開条件を残して進めます。候補の数を埋めるために監視作品や対象弾を増やしません。

通常は税込定価105%以下、通常のポケカ30th CELEBRATION BOXだけ200%以下、送料別。GD01・GD05・通常30th BOXを維持し、個別上限、停止した対象、履歴、送信済みIDを守ります。
