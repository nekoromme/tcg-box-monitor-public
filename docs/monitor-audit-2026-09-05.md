## 結論と確認範囲

漏れは店舗別の例外だけではない。検索条件、一覧→詳細の遷移、商品単位の分類、OCR、検知実績の評価に共通の不具合があった。112ソース定義（実行対象104、無効8）と、保存されている86スナップショットを棚卸しした。過去の会話は検索できた範囲を照合しており、全会話を網羅したとは断定しない。

保存履歴の基準は monitor-state の `82b4c0b4438666878f03ee82b2cfa07fa560d5ad`。この保存範囲で候補生成が一度も記録されていない実行対象ソースは51本だった。これは「全期間一度も動いていない」ことや「51店舗で開催中の抽選を漏らした」ことの証明ではない。取得専用ページ、未開催、期限切れ、対象外応募、アクセス拒否を区別する必要がある。

## 共通原因と変更

| 層 | 問題 | 対応・検証 |
|---|---|---|
| 検索 | 商品名・抽選キーワード付き検索に出ない公式投稿を拾えない | 有効な公式系Xソース60本へ、同じアカウントの無絞り込み検索を追加。別店舗・二次情報の検索範囲は広げない。60本の接続をテスト。 |
| 本番設定 | 定義したソースが無効／本番の代替経路につながっていない | 実際の有効ソースとフォールバック関係を棚卸し。コジマは稼働中の店舗別経路で実証。 |
| HTTPキャッシュ | 本文キャッシュがないのに304で再解析・詳細巡回・OCR再試行を省略 | 本文を保存する実装ができるまで条件付きGETを無効化。過去ETagがあっても再取得・詳細再解析するテスト。 |
| 一覧→詳細 | ポケセンの `/news/?id=...` を一覧と誤認、楽天の詳細未巡回、イトーヨーカドーの抽選ページを除外 | 個別ルーティングを修正し、実際のURL形式を回帰テスト化。ポケセン直取得の403は未解決と明記。 |
| BOX分類 | 最初の括弧やデッキ名を選び、同じ投稿のBOXまで除外 | 商品カテゴリーに結び付いた名前を優先し、除外商品名を飛ばして次の候補を見る。長命ヶ丘の実OCRで再現・検証。 |
| OCR | 月・日をA/Hと誤読し、開始日不明で停止 | 日付の形に限定して正規化。東仙台の実OCRで開始・締切が別々に取れることを確認。OCR後にも公式商品カタログと照合。 |
| 日時 | `9/3 17:59` の空白を消すと `9/31 7:59` に誤解釈 | 日付と時刻の境界を保持する。締切を開始日として採用しない。 |
| 応募条件 | 本文だけで除外し、画像中の店頭QR・リポスト条件を再判定しない | OCR後に共通除外を再適用。リポスト表現の漏れを修正。本文・画像の双方でテスト。 |
| 日付の保存 | ふるいち・ホビーサーチの初回検知日が毎回変わる | 初回通知履歴と既存イベントIDを再利用。通知のやり直しや新しいイベント作成はしない。 |
| 監視評価 | HTTP200や他店の候補があれば「代替経路が正常」と見なす | 同じ店舗・作品の実候補がある場合だけ代替の成立とする。詳細ページ失敗・候補ゼロをHTTP成功で隠さない。 |
| 実証記録 | ソース全体の結果しかなく、未実行の個別URLも動いたように見える | URL別に取得・遷移・解析・除外理由・候補実績を保存。過去にない記録を推定で埋めない。 |

楽天ブックスの一覧はブラウザでも空を確認したため、JavaScriptを使えば候補が出ると推測して方式を変更することはしていない。実在する公式詳細ページでは商品と受付期間を取得し、現在は終了済みとして通知しないことを本番で確認した。

## 未実証・制約を残す箇所

全104ソースを「抽選を必ず検知できる」と保証する段階ではない。403・bot対策・アプリ内限定、公式投稿の検索未収録は、パーサー修正だけでは解消できない。アクセス制限の回避、未提供の認証情報利用、応募条件の無断緩和は行っていない。

ポケセンオンライン、キッズリパブリック、ヨドバシ、KONAMI STYLE、タカラトミーモール、ミニストップ、DMMホビー、HLJなどの直接取得には失敗が残る。Yahoo本体が読めても予備ミラーが403になった経路は、予備経路未実証として区別する。ポケ堂盛岡・北上は今回の検索投稿自体がゼロで、未開催なのか検索未収録なのか断定できない。

ロルカナ公式の商品経路は、今回ゼロでも「初めから未作動」ではない。保存範囲で過去候補実績53回。最新掲載商品の公式発売日が7月17日で、現在の45日範囲外になることを一次ページで確認した。[公式商品ページ](https://www.takaratomy.co.jp/products/disneylorcana/product/attack-of-the-vine/booster-pack/)

作品・移動範囲・無効化した店舗、BOX以外・リポスト・店頭QRのみの応募除外は維持。シュリンクを外す条件は、会話で確認した「中身の開封と区別する」既存運用を変更していない。
