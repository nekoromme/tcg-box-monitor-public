# 別経路からの同じ抽選を一度だけ通知する

2026-10-24以降の保存済み実配信履歴を照合し、次の6組の重複を確認した。

| 店舗 | 商品 | 重複した取得元 |
| --- | --- | --- |
| イオンスタイルオンライン | 神の支配 | スニダン / 入荷Now |
| ゲオ | 神の支配 | スニダン / 公式X |
| キッズリパブリック | 神の支配 | 二次情報X / スニダン |
| プレミアムバンダイ | Heroines Edition vol.2 | 公式Xの2アカウント |
| フルコンプ仙台 | Heroines Edition vol.2 | 公式X / 入荷Now |
| 古本市場・ふるいち | Heroines Edition vol.2 | 公式ニュース / 公式X |

原因は商品コードの省略、ブランド名と引用符の違い、および開始日を読めない経路が仮の検知日を使うこと。商品名とコードの比較を共通化し、同一店舗・商品・受付開始日の候補を統合する。開始日不明のX告知は、投稿日時と仮開始日がともに明記された受付期間内にある場合だけ同一募集へ照合する。個別ニュースIDを持つふるいちは既存の募集記事単位の識別を維持する。

別店舗、異なる商品コード、明記された異なる回次、次回の受付期間は別件として残す。取得元を丸ごと停止しない。どの経路が先でも通知済み履歴とカレンダーIDを引き継ぎ、後から公式が読めた場合は公式の案内を優先する。

既存の定期実行の事前修復処理で、確認期間に既に配信済みの同一募集だけを整理する。Discordへの整理通知は送らない。カレンダーは残す予定を確認してから所有権を検査できる余分な予定だけ削除する。処理済みマーカーと途中の移行履歴を保存し、再実行でも再通知・再登録しない。

実配信の公開情報だけを抽出したfixtureで、両方の到着順、再起動、同一巡回、通知済み履歴、次回抽選の分離、カレンダーの整理と再実行を回帰確認する。運用状態全体・秘密情報・実カレンダーIDは追加しない。
