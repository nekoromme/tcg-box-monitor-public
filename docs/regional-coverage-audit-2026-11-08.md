# 近隣トレカ抽選監視の点検（2026-11-08）

対象はユーザー指定の盛岡〜石巻、一関〜気仙沼周辺。内陸の盛岡・紫波・花巻・北上・奥州・一関、宮城県北の栗原・登米・大崎・涌谷・石巻・気仙沼を照合対象とした。全国・チェーン共通抽選と店舗独自抽選を区別する。対象地域内の全販売店や非公開・店頭限定告知を網羅したという意味ではない。

## 実際に確認した検知漏れと修正

ポケ堂北上店「30th CELEBRATION」購入抽選。

- 公式投稿: https://x.com/Pokedou_Kitakam/status/2118591090244947978 （11/6投稿）
- 原画像: https://pbs.twimg.com/media/HWa_XYRbQAE_KiX.jpg?name=orig
- 締切11/12 23:59、1BOX7,200円、シュリンク付き。フォロー＋RPで応募し当選後に店頭購入。購入11/13〜11/15。
- 原画像に応募開始日の記載はない。投稿日を実際の開始日と断定しない。
- 本番保存履歴では同店舗の案件0件。対象募集は検索結果に存在したが、劣化したOCRにある「当選者」を理由に当選者向け案内として除外されていた。
- 有料購入抽選の応募手順が本文に明示された場合は、画像の当選者向け注意事項だけで募集を除外しないよう共通判定を修正。
- 当該画像は締切OCRも欠落していたため、公式画像を目視確認した締切を既存の投稿別補正設定へ登録。実際の開始日は不明と表示する。
- Yahoo本文には店名ハッシュタグが商品名より先にある。既に本文と一致した公式カタログ商品があるときは、店名の一部を商品名として採用しない。
- 実取得したYahoo入力＋現在のOCR履歴＋公式商品カタログで、正しい商品名と締切の候補1件、エラー0を確認。
- 無料企画、当選発表のみ、店頭QR応募、期限終了後、同一投稿の再取得は回帰テストで確認。取得サイト・定期ジョブの追加なし。

## 未登録・独自告知を保証できない候補

| 地域 | 候補 | 確認結果／限界 |
|---|---|---|
| 一関 | パワーナイン | 現行設定に個別登録なし。公式サイトと直近49投稿を確認。今回確認した期間の対象BOX抽選の見逃しは確定していない。 |
| 盛岡・矢巾 | ジョニー青山・アルコ | 現行設定に個別登録なし。青山20投稿は部分取得、アルコは公開API取得失敗。対象抽選がないと判断しない。 |
| 盛岡 | ホビースクエアにしな | 個別登録なし。19投稿を部分取得。過去の店頭QR抽選情報はあるが、現行のオンライン応募対象の取り逃しとは別。 |
| 盛岡 | 駿河屋MOSSビル店、BOOKOFF各店 | 個別登録なし。店舗公式情報で実在確認。対象の店舗独自抽選について継続取得を保証できない。 |
| 北上 | 町のトレカ屋さん、アメリカンパラダイス、万SAI堂 | 個別登録なし。前2店の公開投稿を部分取得。対象作品外の商品予約・模型予約・大会募集をBOX抽選に数えない。万SAI堂は公開API取得失敗。 |
| 気仙沼・石巻 | フジヤ気仙沼、シーガル石巻／イオンモール石巻 | 共通ガルモバ告知は既存経路あり。各店独自告知は別途保証がない。イオン石巻の11/7告知はスペシャルデッキセットMEGAで、通常BOX抽選とは区別する。 |

「未登録」は「いま応募できる対象BOX抽選を見逃した」と同義ではない。検索で見つからないことや公開APIの404は、対象情報が存在しない証拠ではない。
