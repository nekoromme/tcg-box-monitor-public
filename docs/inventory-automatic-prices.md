# 在庫通知の設定・新弾価格の自動登録

## 通知の設定場所

https://tcg-cross-search.purplepearl-v.workers.dev/automatic.html に、Discord自動通知の実際の対象・停止理由・上限を表示する。以前の `/monitor.html` は端末ごとの個別監視として残し、用途を明示する。

商品の「通知対象・上限を変更」からGitHubへ進み、所有者本人が設定依頼を送信すると `inventory-settings` が実行される。公開画面に通知用の秘密情報を渡さない。所有者以外の依頼は実行せず、値は商品ID・整数の割合・金額・有効/停止だけを受け付ける。

設定は `config/inventory-notification-policy.json` の `productSettings` に履歴付きで保存し、既存の `inventory-sync` を呼び出して反映・再読み込み・新しい巡回完了まで確認する。成功後に依頼を閉じる。失敗時は依頼を残し、Actionsに原因を記録する。市場判断による停止の根拠は `pausedProducts` に維持し、所有者が明示した有効/停止が優先する。

## 新弾の公式価格

1. 既存の公式発売情報から新弾を追加する。
2. 同じ定期処理で公式商品ページの税込価格を取得する。
3. 公式BOX価格があれば直接採用する。パック価格だけの場合は、その商品の公式入数、または監視で確認済みの新品BOXの商品名に書かれた入数を掛ける。
4. 商品名・作品・型番を照合する。入数の補完先はメディアワールドとマスターズスクウェアの確認済み商品に限定。店舗の販売価格は定価に使わない。シリーズの過去商品から入数を推測しない。
5. 出典・確認時刻・計算方法を `inventory_prices.json` に残し、監視本体へ渡す。新しい価格の登録後は商品を再取得してから通知判定する。

未発表・入数未確認は6時間後、確認済みは7日後に再確認する。1実行最大16商品・90秒を目安にし、未確認を優先する。これは定期処理が正常に起動した場合の目安で、遅延時は後ろへずれる。一時失敗で確認済みの定価を消さない。新弾同期でも登録済み定価・個別上限・停止・送信済みIDを保持する。

通常は定価105%以下、30th CELEBRATION通常BOXのみ200%以下。金額上限もある場合は厳しい方。送料別。定価を確認できない間は在庫履歴を残し、通知を保留する。

## 週ごとの見直し・巡回の見える化

`inventory_market_review.json` に週1回、監視店で定価105%以下の在庫を24時間以上・3回以上連続観測した商品を除外候補として保存する。取得失敗・売切れをまたぐ区間や一瞬の安値を根拠にしない。市場全体の成約価格や利益の判定ではないため、自動停止・再開は行わない。

既存の頻度調整（一覧30/60/10分、最大3店の重点枠）を維持する。商品ごとの確認間隔と、実際の検知から通知受理までの時間を画面へ表示する。観測の間に完売した販売の速さは推測しない。

## 検証用資料

`tests/fixtures/inventory-prices-2026-10-04.json` は2026年10月4日に取得した公式ページの価格・入数部分。税込と税抜、関連商品の別価格、価格未発表、1箱10/15/16/24/30パックの違い、他作品の同じ型番、キャッシュ・失敗後の保持を検証する。外部通知の追加送信はテスト内で行わない。
